# Checklists

## Rotina Diária
- Verificar contas com vencimento no dia.
- Verificar contas vencidas ou próximas do vencimento.
- Conferir recebimentos de clientes.
- Conferir pendências financeiras abertas.
- Atualizar registros financeiros necessários.
- Separar documentos ou informações que precisam de aprovação.
- Comunicar riscos de atraso para [PENDENTE DEFINIR].

## Rotina Semanal
- Revisar calendário de contas a pagar.
- Conferir se todas as contas da semana foram registradas.
- Verificar comprovantes pendentes de organização.
- Conferir recebimentos em aberto.
- Revisar lista de clientes inadimplentes.
- Atualizar relatório de inadimplência.
- Organizar cobranças a serem realizadas.
- Comunicar pendências relevantes para [PENDENTE DEFINIR].

## Rotina Mensal
- Conferir contas pagas no mês.
- Conferir contas ainda pendentes.
- Organizar comprovantes do período.
- Revisar recebimentos de clientes.
- Consolidar relatório de inadimplência.
- Identificar valores em atraso.
- Identificar cobranças sem retorno.
- Levantar pendências financeiras que precisam de decisão.
- Encaminhar relatório mensal para [PENDENTE DEFINIR].

## Antes de Realizar Pagamentos
- Conferir fornecedor, cliente ou favorecido.
- Conferir valor.
- Conferir vencimento.
- Conferir descrição da conta ou documento de origem.
- Conferir se a conta já não foi paga anteriormente.
- Confirmar forma de pagamento.
- Confirmar necessidade de aprovação com [PENDENTE DEFINIR].
- Não realizar pagamento com informação incompleta.

## Após Realizar Pagamentos
- Salvar ou registrar o comprovante.
- Vincular o comprovante à conta correspondente, quando aplicável.
- Atualizar status da conta como paga.
- Conferir se o valor pago foi o correto.
- Registrar data do pagamento.
- Comunicar pagamento realizado, quando necessário.

## Conferência de Recebimentos
- Conferir cliente.
- Conferir valor recebido.
- Conferir data do recebimento.
- Conferir forma de pagamento.
- Verificar se o recebimento corresponde a uma venda, parcela ou acordo.
- Atualizar status do cliente ou título.
- Registrar divergências encontradas.
- Encaminhar divergências para [PENDENTE DEFINIR].

## Cobrança de Clientes
- Verificar se há valor vencido.
- Conferir histórico do cliente antes de cobrar.
- Conferir valor atualizado da pendência.
- Utilizar linguagem profissional e respeitosa.
- Registrar tentativa de contato.
- Registrar retorno do cliente.
- Registrar promessa de pagamento, se houver.
- Acompanhar se o pagamento foi realizado na data combinada.
- Encaminhar casos sem retorno para [PENDENTE DEFINIR].

## Organização de Registros
- Manter comprovantes em local definido.
- Manter relatórios atualizados.
- Registrar pendências com clareza.
- Evitar informações financeiras soltas em conversas sem registro.
- Conferir se documentos importantes estão acessíveis aos responsáveis.
- Proteger dados financeiros e pessoais.
